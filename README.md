# Input Tester

![Input Tester by emoc4n](https://github.com/emirluau/InputTester/blob/asset/header.png?raw=true)

Input Tester is a program designed to simply and quickly test your game controller. It was developed using the Godot Engine.

## Features

* Test buttons.
* Minimalist and user-friendly interface.
